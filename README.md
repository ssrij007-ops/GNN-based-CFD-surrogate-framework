# GNN-based-CFD-surrogate-framework
Coupling OpenFOAM-generated high-fidelity flow data with graph neural networks to predict multi-regime cavitating flow.
This work presents PRANO-Cav (Physics-aware Regime-aware recurreNt netwOrk for Cavitation), a mixture of experts (MoE) surrogate predicting cavitation flow fields and force coefficients over Clark-Y hydrofoil across all regimes [inception, sheet, cloud, and supercavitation] simultaneously. A shared Gated Recurrent Unit (GRU) backbone, conditioned on global operating parameters, routes each sample through regime-specific expert heads via a learnable gating network, with a jointly trained regime classifier providing interpretable regime identification at inference time. Training only on 12 Large Eddy Simulation (LES) cases (Schnerr-Sauer; σ ∈ {0.28-1.4}; Re ∈ {5×105-1.2×106}; 1500 Central Processing Unit (CPU)-hours) and evaluated on four-held out interpolation and extrapolation cases.
